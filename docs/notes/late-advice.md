# Late advice: which prover statements are admissible at which stage, and at what price

WIP. The numbers below are computed and pinned by
`tests/veritor/analysis/test_late_advice.py`; the prose of sections 1-7 is
still to be written out from the conclusions recorded here. Default is
prohibition: every (stage, kind) cell not priced below is PROHIBITED.

Notation: `u(1) = W_V + log2 |S|` (`unit_fault_bits`); `u_post(1) = U_0(eta (1 - s)) - U_0(eta) = rho log2 (1 / (1 - s))`, which is `(u(1) + 1) / q` at the scattered channel; `mu_f` the largest Poisson mean with `P[X <= f] > eta` (`mu_0 = 27.73`, `mu_1 = 31.20`, `mu_2 = 34.15` at `eta = 2^-40`).

## Conclusions so far

1. Adversary model: challenges are PRFs of digests. `J = bernoulli_subset(q_seed, boundary_phase(header, boundary))`; `T = bernoulli_subset(s_seed, interior_phase(replay_phase, InteriorMessage))`, and `InteriorMessage.manifest` includes `declarations`, so the sample binds every declaration (`protocol/phases.py`, `protocol/challenge.py`, `protocol/messages.py`). Epoch: `derive_run_seed(round_seed, seal, round, run, b"q"|b"s")` HMAC, round seed verifier-private.

2. Ladder. Pre-J (and compile time) pardons of any kind are priced by the fixed-in-advance argument: VU `u(1)`; RU-scope `W_R + log2 n_RU`; source cell `log2 n_W + W_cell` run-wide (`+ log2 n_RU` for one RU); port `W_port + log2 (n_RU n_ports)`. Post-J: VU pardon = `declared_bits` = `min(U_0(eta (1-s)^f), U_0(eta / (1 + |S|)^f) + f u(1))`, both bounds verified (bound (i) is tight: the scattered attack with `q N >> f` opened errors realises `(1-s)^-f`); RU-scope `<= f [rho log2 (1 + q n_RU / (1 - q)) + W_R + log2 n_RU]` (proof: union over pardoned sets `P`, `sum_P prod_{r in P} q / f(l_r)`, `f(l) >= 1 - q`) and `>= Delta mu W_R / q` (whole-RU attack) -- 0.10 to 0.47 `U_0` per pardon at the headline, PROHIBITED; source/port pardons `<= d u_post(1)` (`d` = readers of the cell in the RU, 1024 at the 70B shape) = declaring every reader, no proof of anything cheaper, PROHIBITED. Post-s: everything PROHIBITED; attack: pardon exactly the sampled bad VUs, price `~ Delta mu u(1) / (q s)` = 2.4e12 bits for the first pardon at the headline (12.5% of `U_0`, 390 x the post-J price), 1214 bits > the whole 480-bit output at the simulation policy.

3. Late lowering: PROVEN at the compile-time price under (1)-(7). Key step: locality gives `E_J[max_v prod_{r in J} g_r(v_r)] = max_v sigma_v(E_v)` exactly (per-RU choices, independent Bernoulli coins), so `Y = union_v Y_v(eta)` and `|Y| <= 2^{A + max_v U_v(eta)}`, `A = sum_R log2 |V_R|` over ALL RUs. The sketch's `sum_v` step would instead divide the threshold by `2^A` (cost `rho A`); locality removes it. `A` counts every RU because of the rounding channel (distinct floating-point lowerings give distinct honest outputs at acceptance 1); it is the compile-time price, but at the headline one bit per request is 2.9e13 bits = 1.5 `U_0` -- name variants per kind, or make them a checkable function of public placement (M3, free). Condition (4): the fold is monotone in the per-kind series (`multiply`, `power`, `cap`, knapsack, Laplace); the verifier folds the union-of-variants table (sound for mixed assignments; at most `log2 |V_R|` looser per erroneous RU at the scattered channel); the pure worst variant is exact on the Laplace path only under pointwise dominance. Caveat: the error truncation moves with the grid, so at `max_buckets = 2048` the fold is not monotone in `eta` on saturated tables (small table: 1895.8 at `eta`, 1887.1 at `eta (1-s)`; stable 1894.5 at a fine grid) -- sound, but `bound(max_faults=f).bits` can come out below `bound().bits`. Conditions (1), (5), (6) are exactly what forbids the feared case; no value may ride along (a parametrised family is admissible only if finite, in the header, counted in `|V_R|`). A shared (non-local) post-J choice is charged `rho log2 |V|` or prohibited.

4. Epoch: no gap. `EpochVerifier._capacity` folds `union(tables)` at `eta / rounds` with the round's `max_faults`; `receive_interiors` enforces the round total (`test_the_fault_budget_is_the_rounds_to_share`). Both adaptive bounds are pointwise/union bounds, so the sequential release of the runs' `SampleChallenge`s within a round changes nothing. A per-run budget would understate by `(R - 1) f_max u_post(1)`. The verifier-private round seed is load-bearing for M6, not only against interior grinding: a public `s_i` turns declarations into post-s pardons (390 x dearer).

5. Conservation law: `p_k in {1, q, q s}`, leverage `1 / p_k`; expected charge `p u(1) + (1 - p) u_post(1)`, so detection must miss fewer than a fraction `~ q` of faults for pardons to be cheap; no algebraic shortcut in floating point (Freivalds out of scope); structure may be late for free, values may not.

6. Prices (pinned by the test). Headline (`q = 1.57e-8`, `s = 8.91e-3`, `rho = 4.74e11`, `U_0 = 1.90e13`, `|S| = 2^78.7`, `W_V = 16`, `u(1) = 94.7`, `n_RU = 2.93e13`, `W_R = 8192`): post-J VU 6.12e9 per pardon = 3.2e-4 `U_0` = 1.015 `u(1) / q`; bound (ii) 3.73e13; post-s first pardon 2.37e12 = 0.125 `U_0`; RU pre-J 8237, post-J 0.47 `U_0` (attack 0.095 `U_0`); source pre-J 51.9, post-J 0.33 `U_0`; one bit of lowering per RU 1.55 `U_0`. Simulation (`theta = (1/2, 1/8)`, `|S| = 3791`, `W_V = 64`, `u(1) = 75.9`, `n_RU = 20`, `W_R = 224`, `|Out| = 480`): the fold is saturated (uncapped 1894.5 at every threshold, capped 480 with or without a budget); slopes `rho = 755.9`, post-J 145.6 per pardon (`u(1)/q = 151.8`), union bound 9062, post-s 1214, RU pre-J 228.2, post-J 3267; at `theta = (1, 1)` exactly `f u(1)`.
